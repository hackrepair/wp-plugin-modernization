# Support

## Using WP Plugin Modernization

Open a GitHub issue for reproducible bugs and focused feature requests. Use a minimal synthetic fixture and remove private plugin source, credentials, customer data, and sensitive filesystem paths.

This early-development project does not guarantee response times or compatibility with every WordPress plugin shape.

## Security issues

Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting. Do not disclose an unpatched vulnerability in a public issue.
