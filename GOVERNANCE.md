# Governance

WP Plugin Modernization is maintained by Jim Walker, The Hack Repair Guy.

## Decision making

The maintainer has final responsibility for project scope, releases, security decisions, and merge approval. Decisions should preserve the project's core boundaries:

- Local and read-only operation by default.
- Evidence separated from interpretation and remediation.
- Explicit partial and unavailable checks.
- No security, compatibility, or malware-free verdict based only on a quiet scan.
- No private plugin source, credentials, customer data, or sensitive paths in public project artifacts.

Community proposals are welcome. Changes are evaluated on correctness, usefulness, maintenance cost, privacy, false-positive tradeoffs, and fit with the published roadmap.

## Maintainer succession

If maintenance changes hands, repository ownership, release authority, security-advisory access, and signing or publication credentials must be transferred deliberately. No contributor receives release authority solely by submitting code.
