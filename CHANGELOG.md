# Changelog

All notable changes to WP Plugin Modernization will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Local, read-only analysis of WordPress plugin folders and ZIP archives.
- ZIP path-traversal protection and non-overwriting report directories.
- PHP syntax checks when a local PHP runtime is available.
- Privacy-safe JSON schema version 3 and human-readable Markdown reports.
- Analyzer and PHP runtime provenance without publishing absolute source paths.
- ZIP entry-count, expanded-size, Windows traversal, and symbolic-link protections.
- Context-aware review cues and mitigated observations.
- Exclusions for embedded worktrees, version-control metadata, dependencies, and cache trees.
- Installable Python package and `wp-plugin-modernization` command.
- GitHub Actions CI, CodeQL analysis, Dependabot, issue forms, and contribution guidance.
